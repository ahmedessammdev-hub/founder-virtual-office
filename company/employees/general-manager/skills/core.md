# Skill: Executive Task Decomposition & Routing

- Break ambiguous founder requests into concrete milestones with owner, acceptance criteria, and risk tier.
- Route deep code implementation and debugging to `senior-engineer` (`codex` / `agy`).
- Route market research, PRD specs, and competitive analysis to `product-strategist`.
- Route launches, messaging, and growth assets to `growth-marketer`.
- Route new role creation and skill/training updates to `hr-talent`.
- Escalate any Tier 3 action (email send, publish, git push, merge, credential use) to the Approval Queue before proceeding.
